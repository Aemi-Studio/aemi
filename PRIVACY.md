# Privacy Policy

`Aemi` is an open-source Swift foundational library suite (memory, kernels, I/O, hashing, process helpers), licensed under the MIT License.

## Data Collection and Telemetry

- **No telemetry or analytics:** `Aemi` collects, stores, and transmits **zero** telemetry, usage analytics, crash reports, or personal data.
- **No network access:** `Aemi` performs no outbound network requests and contains no tracking, licensing, or phone-home logic.

## Data Processed Locally

As a compiled Swift library, `Aemi` processes only the in-memory inputs and local filesystem paths provided directly by the host application or tool that links it.

## GDPR and Enterprise Compliance

`Aemi` operates strictly within the calling process and transmits no data to external services.
