# Diary — 2026-10-20 (01)

## Interned strings, measured from a consumer

Prompted by an AemiSDR review (its diary 2026-10-20-01 has the full probe and commands). The result that
concerns this package, `swiftc -O`, Swift 6.4, `SI` copied verbatim, 100,000 reads × 9 rounds, two runs:

| Read | median | allocations/read |
|---|---|---|
| `@Interned` getter, 11 B | 155 ns | 2 |
| `@Interned` getter, 27 B | 255–259 ns | 3 |
| `static let` of the same expression | 0.9 ns | 0 |

| Claim | Probe | Verdict |
|---|---|---|
| The byte literal allocates per read | count with `malloc_logger` | **REFUTED** under `-O`: 2 allocations for an 11-byte name are the permutation and output arrays |
| `@Interned` caches its result | read the macro (`InternedMacro.expansion`) | **REFUTED**: getter re-decodes |
| Expansion is deterministic | read `InternedObfuscation.make` | **REFUTED**: `UInt64.random` per expansion |

Open: the same numbers through the real package (cross-module `@inlinable`), with `expectAllocations`.

Decisions proposed: ADR-0012 (decode once, deterministic keys, typed forms), ADR-0013 (one synced
white-paper core). Delivered as a branch from a clone; the working tree of this repository was not touched.
