# 2026-11-02 (01) — What Litmus needed from aemi (ADR 0028)

Litmus, the mutation tester, listed nine gaps it had worked around (its `docs/upstream-recommendations.md`, AE-1 to
AE-9). All nine are in this change; each claim below was checked here, on the shared 8-core M3 (macOS 27.0.1, Xcode
27.2), unless it says otherwise.

## Ledger

| Claim | Probe | Verdict |
|---|---|---|
| A group kill misses processes that left the group | a child that calls `setpgrp`, then the group is killed | Holds: Litmus' timed-out mutants left two `swiftpm-testing-helper` orphans for 2.5 h |
| The session still finds them | `getsid` of the orphan | Holds: the dead leader's pid; `ProcessTable.members(ofSession:)` lists leader and grandchild (test) |
| `KERN_PROCARGS2` gives every same-user environment | `ps eww` and `KERN_PROCARGS2` on `/bin/sleep`, `/usr/bin/perl`, Homebrew bash | **REFUTED**: empty for Apple platform binaries, full for others; the session is the key that always works |
| Reading environments of every process is cheap | 414 processes | **REFUTED** at 35 ms a sweep; 0.45 ms when only processes started after the command are read (Litmus) |
| `proc_pid_rusage` reports nanoseconds | `ri_user_time` on Apple Silicon | **REFUTED**: Mach ticks; converted with the timebase, exactly (full-width product, then division) |
| Per-child usage can be had from the runner | swift-subprocess 1.0.2 source | **REFUTED**: it reaps its children; swiftlang/swift-subprocess#226 (open) adds `resourceUsage`. Until then: `childrenCPUNanos` (exact one child at a time) and live sampling |
| `clonefile` clones in the temporary directory | 3 MB file copied | Holds: `.cloned` on APFS; the read-and-write path tested directly |
| `O_EXCL` refuses a dangling link | a link to a missing file | Holds: `EEXIST`, and nothing is created at the link's target |
| CommonCrypto and the portable SHA-256 agree | NIST vectors, one million `a`, 200 random inputs in random pieces | Holds |

## Numbers now

`swift:6.4` container through a harness package holding the new and touched suites (aemi's own `swift test` does not
build on Linux: AemiCore imports Combine). CI's Linux job now also builds `AemiProcess`.
