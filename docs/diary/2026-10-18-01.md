## Count only the measuring thread (ADR-0010)

Atelier's lexer ceiling kept failing in full suites (minimum 191 against a bound of 4) and passing in
isolation. Red test first: a fresh thread allocating 10,000 times inside a window added 10,008 to the
count. The hook now counts only the thread that called `begin` (`pthread_equal` against a recorded
owner). The new test passes; the suite reports 535 tests, exit 0, job `job-198`. The pedantic C
settings compile the change with `-Werror`.

This contradicts ADR-0008's mechanism ("warm threads are invisible"). Counts from other threads are
unreliable both ways, so the counter no longer reports them at all.
