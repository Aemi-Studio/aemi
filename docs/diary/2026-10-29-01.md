# Diary — 2026-10-29 (01)

## File watching promoted into AemiIO (ADR 0016)

Atelier's FSEvents `FileWatcher` and ask's kqueue directory watch moved into AemiIO behind one `FileWatching` protocol, with a new
`KqueueWatcher` for configuration-sized sets of paths. The FSEvents code was ported without Foundation: C-string event paths, a
hand-built `CFArray`, failures to a closure.

| Question | Probe | Verdict |
|---|---|---|

| Is a file under missing directories seen once they are made? | `mkdir project; mkdir project/.ask; write config.json` while watching the file | **Not always** (one timeout in eight runs). A directory made between choosing the new anchor and registering it raised no event. The anchor is now chosen again until it holds: 0 failures in 40 runs of the kqueue suites. |
